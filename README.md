# Insurance-Risk-Algorithm

## Abstract
This repository examines two unsupervised learning methods, k-means clustering and its extension, fuzzy k-means (fuzzy clustering), and evaluates their performance on the Kaggle insurance claims dataset. While k-means assigns each observation to a single cluster, fuzzy k-means allows partial membership across multiple clusters, offering greater flexibility in capturing overlapping data structures. We provide both intuitive and technical explanations of each method and apply them to identify patterns within insurance claim data. The results show that fuzzy k-means provides a more flexible representation of overlapping data structures, though in this application it produces less distinct and less actionable clusters compared to k-means.  However, this comes at the cost of increased computational complexity and reduced interpretability. Overall, the findings suggest that fuzzy k-means can offer meaningful advantages over traditional k-means in real-world datasets with ambiguity, though the benefits depend on the specific application and trade-offs between accuracy and simplicity.

## Discussion
After exploring how K-means and fuzzy K-means perform on medical insurance data, we can see important insights derived from each approach and ways that we can improve our analysis using extensions of clustering methods. The first obstacle we faced was the format of the variable in our dataset. Euclidean distances are not equipped to handle mixed data types; we had to exclude categorical variables altogether. To include these variables in future clustering attempts, we would have to use an extension of K-means, such as K-medoids or any other appropriate distance measure, like Burt distance.

Although we decided to use all of our numerical variables, there could be concerns with correlated variables, double-counting, and skewed distributions. Many of the discrete, count variables had heavily skewed distributions, which affects where K-means places the cluster centers. Additionally, our insurance data violates the K-means assumptions that all clusters should be relatively equal. This is often not the case with insurance data, where there is a larger low-risk group and a smaller high-risk group. This shows us the limitations of applying the standard k-means clustering approach to insurance data.

However, there were still some interesting takeaways from the K-means analysis. In standard K-means, the algorithm was able to find an acute care segment in the data, which was our cluster with a high number of days hospitalized in the last 3 years, which disappeared in fuzzy K-means as the fuzziness parameter increased from 1.2 to 1.3. Both the summary tables and the PCA plots show how K-means used the PC2 boundary to isolate that group, while fuzzy K-means ignored it.

On the other hand, fuzzy K-means found a more comprehensive profile within each cluster, where points within a cluster were more similar to each other and more different from other clusters, which is supported by the difference in medians for each cluster in the fuzzy K-means summary.

Because of the context of health data, standard K-means has provided the most actionable insight by revealing the group with the most acute conditions, and therefore the highest cost, despite not being the group with the highest number of conditions and utilization. The fuzzy K-means output may still be useful in customer stratification, but for reasons other than risk analysis.

This is a good introduction to exploring how K-means can be used in real-world settings. There are still considerable improvements that need to be made to derive real actionable insights. By keeping only numerical data, we left out many variables that may be influential in risk classification, such as smoking status, gender, etc. If these variables are included in other K-means extensions, the results may conflict with the assumptions made in this paper. Additionally, there were possible multicollinearity issues in this feature space. There were a few features that were moderately correlated with each other and influential in PC1: total claims paid, chronic_count, annual_medical_cost, claims_count, visits_last_year, and avg_claim_amount. Many of these variables are related to the cost of claims, and collective correlation in PC1 can make these cost variables seem more influential than they really are. When attempting to drop correlated features, the results became convoluted and uninterpretable. Proper feature selection with insurance data is another area to review and improve upon in future iterations. We could also implement more robust cluster validation between methods. Given all these methodological challenges faced in this analysis, the experimental steps taken to apply K-means and fuzzy K-means to a realistic dataset offer a valuable insight into how these methods succeed and fail in practice.
